# 2번 무역 & 기름 — 골든 룰 (E3)

E5에서 나오는 답이 채점 전에 지켜야 할 규칙이다. 검사 스크립트([check-golden-rules-oil-trade.py](../experiments/scripts/check-golden-rules-oil-trade.py))가 자동으로 검사한다. 2026-10-15에 정했다. [1번 골든 룰](../ai-consulting/golden-rules.md)과 같은 틀이고, 2번 스키마에 맞게 답의 모양과 G6~G9를 바꿨다. 정답(기대 답) 없이 검사할 수 있는 규칙만 넣었다.

## 1. 하는 일과 하지 않는 일

- 한다: 답의 형식, 출처(원장 번호·위치·근거 문장)가 실제로 있는지, 스키마 목록을 지켰는지, 통제 항목에서 지어내지 않았는지 본다. 05 실험의 층위 1(규칙 기반 검사)과 같은 역할이다.
- 하지 않는다: 답이 맞는지(정답과 비교)는 채점 단계에서 따로 본다. 주장이 근거 문장에 실제로 뒷받침되는지는 판정기(층위 2)가 본다.

## 2. 답의 모양

E5에서 "검색만" 방식과 "그래프 경유" 방식 모두 같은 모양으로 답한다. 파일 하나에 질문별 답을 JSON 목록으로 담고, 칸 이름은 아래 한국어 이름 그대로 쓴다.

| 칸 | 내용 |
|----|------|
| 질문 | Q1~Q10, T1~T5 중 하나 |
| 상태 | "답함", "자료에 없음", "전제가 틀림" 중 하나 |
| 주장 | 목록. 주장마다 주어, 관계([스키마](schema.md) 2절 이름), 값, 분류 체계, 업무 단계, 주체, 근거 일곱 칸. 분류 체계·업무 단계·주체는 해당하지 않으면 빈 문자열 |
| 요약 | 사람이 읽는 답 |

- 근거는 목록이고, 근거마다 원장 번호(정수), 위치, 근거 문장(원문 그대로) 세 칸이다.
- 품목 분류에서 제품 이름이 원문에 직접 나오지 않으면, 원문 용어 근거와 분류 근거를 함께 적는다(근거 두 개). 2번 기대 답을 쓸 때 이 방식을 썼고, 2026-10-15에 허용하기로 정했다. 두 근거가 실제로 이어지는지는 판정기(층위 2)가 본다.

## 3. 골든 룰 9개

| # | 규칙 | 검사 방법 |
|---|------|-----------|
| G1 | 정해진 모양을 지킨다 | 네 칸이 모두 있고, 질문은 Q1~Q10·T1~T5, 상태는 세 값 중 하나, 주장은 목록이며, 주장마다 일곱 칸이 있고 근거는 목록이다 |
| G2 | 답했으면 출처가 있다 | 상태가 "답함"이면 주장이 1개 이상이고, 모든 주장의 주어·관계·값이 비어 있지 않으며 근거가 1개 이상이다. 근거마다 원장 번호·위치·근거 문장이 비어 있지 않다 |
| G3 | 원장 번호가 실재한다 | 근거의 원장 번호가 [sources.csv](sources.csv)에 있는 번호다 |
| G4 | 근거 문장이 원문에 있다 | 근거 문장이 그 원장 번호의 원문(raw/ot-NN.txt)에 들어 있다. 비교 전에 양쪽 모두 공백·줄바꿈을 한 칸으로 줄이고, 줄 끝 하이픈 줄바꿈을 붙이고, 둥근 따옴표를 곧은 따옴표로 바꾼다. 하이픈을 붙여서 찾지 못하면 하이픈을 남긴 채로 한 번 더 본다 |
| G5 | 관계 이름이 스키마에 있다 | 관계가 원문 용어, 품목 분류, 요건 중 하나다 |
| G6 | 닫힌 목록 값을 지킨다 | 관계가 원문 용어·품목 분류이면 주어가 UMO·ULO·PPO 중 하나다. 분류 체계·업무 단계·주체가 채워져 있으면 스키마 3·4절 목록 이름 그대로이거나 "기타: "로 시작한다 |
| G7 | 칸 짝이 맞는다 | 품목 분류는 분류 체계가 있고 업무 단계·주체가 비어 있다. 요건은 업무 단계와 주체가 있고 분류 체계가 비어 있다. 원문 용어는 세 칸이 모두 비어 있다 |
| G8 | 통제 항목에서 지어내지 않는다 | T1·T3·T4는 상태가 "자료에 없음"이고 주장이 0개다. T2는 상태가 "전제가 틀림"이다 |
| G9 | 질문이 정한 조건을 지킨다 | Q1의 모든 주장은 관계가 요건이고, 근거가 모두 원장 4번이며 위치에 "제7조"가 들어 있다. Q2의 모든 주장은 주어가 ULO이고 근거에 원장 17번이 하나 이상 있다. Q3에서 요건인 주장의 업무 단계는 "허가·신고", Q4에서 요건인 주장의 주체는 "처리자"다. Q7에서 원문 용어·품목 분류인 주장의 주어는 ULO, Q8에서는 UMO다. Q8에서 요건인 주장의 주체는 "수출자" 또는 "상대국·경유국 정부"다 |

## 4. 검사 스크립트

- 실행: 저장소 맨 위에서 `python3 deep/07-graphrag/experiments/scripts/check-golden-rules-oil-trade.py <답 JSON 파일>`
- 출력: 검사한 질문 수, 주장 수, 근거 수와 규칙별 위반 목록(질문, 주장 순번, 근거 순번, 규칙, 이유)
- 종료 코드: 0 위반 없음, 1 위반 있음, 2 입력 오류. 질문을 하나도 읽지 못하면 2로 끝낸다. 주장이 0개인 답은 G1·G2·G8로 본다. 05 발견 6(종료 코드 0으로 조용히 실패)을 되풀이하지 않기 위해서다.
- 시험 결과: [golden-rules-oil-trade-test.md](../experiments/golden-rules-oil-trade-test.md)
