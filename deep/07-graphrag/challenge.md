# 3주 챌린지 — 과제 정의

출처: 2026-10-11 발표 뒤 멘토가 준 과제 메시지. 에드워드가 받은 원문을 Cowork가 항목별로 정리했다. 평가·인사 문장과 멘토 계정 정보는 옮기지 않았다.

## 주제

「두 도메인 GraphRAG + 골든 룰 + 내 그래프 뷰어」

## 핵심 질문

자료가 많은 도메인(AI 컨설팅)과 적은 도메인(방산)에 GraphRAG를 하나씩 만들면, 그래프는 언제 도움이 될까? 에드워드 자신의 숫자로 답한다.

(2번 도메인은 무역 & 기름으로 바꾸는 승인을 요청한 상태다. [07 README](README.md) 참고)

## 올리는 곳과 증거

- 이 저장소의 deep/07-graphrag/ 폴더
- 멘토가 매주 저장소를 확인한다
- 커밋 시각이 작업 순서(골든 세트 → 사람 그래프 → 에이전트 그래프)의 증거가 된다. 작업한 날마다 push한다

## 1주차 (10/12~10/18, 점검 10/18(일) 21:00)

- E0 저장소 정리: .DS_Store 3개와 빈 .Rhistory를 지우고 .gitignore에 추가
- E1 두 도메인 범위 + 분류 축(고객/사업/업무 유형 중) 결정, 3줄 판단 기록
- E2 원천 원장: AI 컨설팅 15건 이상, 방산 10건 이상(방산은 "찾았지만 못 쓴 자료"도 센다)
- E3 골든 세트를 그래프보다 먼저: 도메인마다 질문 8~10개 + 통제 항목 4~5개 + 골든 룰 6~10개(검사 스크립트 포함)
- progress/week-1.md 4줄, 리즈 저장소 상호 검토 1장

## 2주차 (10/19~10/25, 점검 10/25(일) 21:00)

- E4 그래프 두 번: 사람 그래프(AI 컨설팅 6건 이상, 먼저·독립적으로) vs 에이전트 그래프(2회 이상) → 정밀도·재현율
- E5 질문 답변 비교: 검색만 vs 그래프 경유. 05의 2층 검증을 그대로 쓰고, 다른 계열 판정기를 1회 이상 쓴다
- progress/week-2.md 4줄

## 3주차 (10/26~10/31, 최종 점검 10/31(토) 21:00)

- E6 내 그래프 뷰어: 오픈소스 JS 라이브러리로 정적 HTML, GitHub Pages(도메인 전환, 종류별 색, 클릭하면 출처 패널, 필터)
- E7 발견 정리: 먼저 적은 예측 vs 실제, 방산 보완
- progress/week-3.md 4줄

## 멘토가 덧붙인 설명

- 1단계를 사람이 하는 이유: 사람 그래프가 정답 그래프가 되고, 에이전트 그래프를 거기에 대어 잰다
- Claude Code 자체를 추출기로 쓰면 유료 API 키 없이도 2단계를 시작할 수 있다

## 꼭 지킬 것

- 정답은 메인 세션까지 도구 수준에서 막거나 저장소 밖에 둔다. 뚫리면 지난번처럼 기록하고 다시 시작한다
- 방산은 산업·시장·정책·공급망 수준의 공개 자료만 다룬다. 무기 성능·기술 사양·수출 통제 정보는 범위 밖이다
- 필수선: 10/31까지 다 못 하면 AI 컨설팅은 끝까지, 방산은 원장·골든 세트·에이전트 그래프·답변 비교까지
- 스터디로 끝내지 말고 지금 하는 일과 어떻게 이어질지도 생각한다
