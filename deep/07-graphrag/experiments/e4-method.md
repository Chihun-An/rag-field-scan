# E4 측정 방법 (1번 도메인)

2026-10-22, 에이전트 그래프 2회를 만든 뒤, 비교 결과를 보기 전에 정했다. Cowork가 제안하고 에드워드가 채택했다.

## 대상

- 사람 그래프(human-graph.csv) 7건: 사례 1, 4, 6, 8, 10, 12, 15
- 에이전트 그래프 1회차(agent-graph-1.csv)와 2회차(agent-graph-2.csv)에서 같은 7건만 잘라 비교한다.

## 닫힌 목록 (고객 산업, 적용 업무, 사용 기술)

- 일치: 사례 번호·관계·값이 모두 같다.
- 일치율(재현율) = 에이전트에도 있는 사람 줄 수 / 사람 줄 수. predictions.md 4절의 "E4 일치율"이다.
- 정밀도 = 사람에게도 있는 에이전트 줄 수 / 에이전트 줄 수.
- 참고값: 수행을 넣고 계산한 일치율과 정밀도.
- 기타: 한쪽만 기타면 불일치, 양쪽 모두 기타면 Codex가 같은 뜻인지 판정한다(schema.md 8절).

## 회차끼리 일관성

- 닫힌 목록 줄(수행 제외)의 자카드 지수 = 두 회차에 모두 있는 줄 수 / 둘 중 하나라도 있는 줄 수.
- 17건 전체와 사람 그래프 7건을 따로 잰다.

## 열린 값 (고객, 해결하려던 병목, 낸 성과)

- 사례·관계마다 사람 값과 에이전트 값을 A/B로 섞어 Codex에 준다. 어느 쪽이 사람인지는 e4-codex-key.json에만 적는다.
- Codex는 값마다 상대편에 같은 뜻의 값이 있는지 판정한다(같음, 없음, 정보 부족).
- 재현율 = 같은 뜻의 짝이 있는 사람 값 수 / 사람 값 수. 정밀도 = 같은 뜻의 짝이 있는 에이전트 값 수 / 에이전트 값 수.
- "정보 부족"은 짝 없음으로 세고, 개수를 따로 적는다.
