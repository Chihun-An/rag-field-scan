# 에이전트 그래프 지시문 (2번 도메인 무역 & 기름, E4)

1회차와 2회차에 이 지시문을 글자 하나 바꾸지 않고 그대로 쓴다. 1회차 전에 커밋했다.

## 작업 폴더

이 폴더에는 schema.md, sources.csv, raw/(ot-01.txt~ot-17.txt)만 있다. 이 폴더 밖의 파일은 열거나 찾지 않는다. 인터넷은 쓰지 않는다.

## 할 일

1. schema.md를 읽는다.
2. raw/ 17편에서 schema.md 규칙대로 줄을 뽑는다. 원장 번호는 파일 번호다(ot-01은 1).
   - 주어는 UMO, ULO, PPO이거나, 이 세 제품과 품목 분류 줄로 이어지는 분류 값이다.
   - 원문에 적힌 것만 넣는다. 추론하지 않는다. 원문에 없으면 줄을 만들지 않는다.
   - 근거 문장은 원문 문장을 그대로 옮긴다.
   - 닫힌 목록 값은 schema.md 3·4절의 이름을 그대로 쓴다. 맞는 값이 없으면 "기타: 한 줄 설명"으로 쓴다.
   - 파일을 처음부터 끝까지 읽어도 되고, 낱말 검색으로 필요한 부분만 찾아 읽어도 된다.
3. 결과를 이 폴더에 agent-graph.csv로 저장한다. 머리줄은 "주어,관계,값,분류 체계,업무 단계,주체,원장 번호,위치,근거 문장"이고, UTF-8, 쉼표 구분이다. 해당 없는 칸은 비운다. 쉼표나 따옴표가 든 칸은 CSV 표준대로 큰따옴표로 감싼다.
4. 보고: 쓴 모델 이름, 관계별 줄 수, 주어별 줄 수, "기타" 값 개수, 통째로 읽은 파일 번호·일부만 읽은 파일 번호·열지 않은 파일 번호, 검색에 쓴 낱말, 판단이 어려웠던 점(원장 번호와 함께 짧게).

## 하지 않을 것

- 다른 그래프 파일 찾기
- schema.md, sources.csv, raw/ 고치기
